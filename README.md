# DirectMe 🚀

**DirectMe** — современный мессенджер с поддержкой:
- 💬 Приватные и групповые чаты
- 📸 Отправка изображений, видео, голосовых сообщений
- 📝 Посты с лайками, комментариями, репостами
- 📖 Сторис
- 🔔 Мгновенные уведомления
- 🌍 Двуязычный интерфейс (RU/EN)
- 🌓 Тёмная и светлая тема
